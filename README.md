# Java Lernprojekt

Codebeispiele, Übungsaufgaben und Notizen basierend auf dem Buch **"Programmieren lernen mit Java"** (8. Auflage von 2025) von Hans-Peter Habelitz.
ISBN-978-3-367-10478-9

Die Dateien werden in Kapiteln gemäss der Buchstruktur gesammelt: 

## Inhaltsverzeichnis

- `kapitel-01/` – Einführung
- `kapitel-02/` – Grundbausteine eines Java-Programms
- `kapitel-03/` – Kontrollstrukturen
- ....
